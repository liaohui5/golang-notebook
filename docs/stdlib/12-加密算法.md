## 加密算法

- https://pkg.go.dev/crypto

这些没有什么记录的, 几乎都是纯函数 `加密算法(a字符串) -> 必定得到b字符串`

只需要用的时候看下文档就好了, 就以最常见的 `MD5` 算法为例

```go
package main

import (
	"crypto/md5"
	"fmt"
)

func main() {
	sum := md5.Sum([]byte("hello"))
	str := fmt.Sprintf("%x", sum)
	fmt.Println(str) // 5d41402abc4b2a76b9719d911017c592
}
```
