| 函数                                                      | 说明                                                                                          |
| --------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| [append(slice, elems)](https://pkg.go.dev/builtin#append) | 向切片末尾追加元素（可多个），返回新切片；若切片容量不足会自动扩容                            |
| [cap(v)](https://pkg.go.dev/builtin#cap)                  | 返回容器的容量：切片/数组返回最大可容纳元素数，通道返回缓冲区容量                             |
| [clear(t)](https://pkg.go.dev/builtin#clear)              | 清空容器内容：切片置零长度（保留容量），map清空所有键值对，通道无操作                         |
| [close(c)](https://pkg.go.dev/builtin#close)              | 关闭通道（仅发送方调用），关闭后无法发送数据，但可接收剩余数据                                |
| [complex(r, i)](https://pkg.go.dev/builtin#complex)       | 创建复数：r 为实部，i 为虚部，返回 `complex128` 类型复数                                      |
| [copy(dst, src)](https://pkg.go.dev/builtin#copy)         | 将 src 切片数据复制到 dst 切片，返回实际复制的元素个数（取两者长度最小值）                    |
| [delete(m, key)](https://pkg.go.dev/builtin#delete)       | 删除 map 中指定 key 对应的键值对；若 key 不存在，无任何副作用                                 |
| [imag(c)](https://pkg.go.dev/builtin#imag)                | 返回复数 c 的虚部，类型为 `float64`                                                           |
| [len(v)](https://pkg.go.dev/builtin#len)                  | 返回容器的长度：切片/数组返回元素个数，字符串返回字节数，通道返回待接收元素数                 |
| [make(t, size)](https://pkg.go.dev/builtin#make)          | 创建并初始化切片、map、通道：切片需指定长度（可选容量），map 指定初始空间，通道指定缓冲区容量 |
| [max(x, y)](https://pkg.go.dev/builtin#max)               | 返回多个同类型参数中的最大值；参数需为可比较类型（如数值、字符串）                            |
| [min(x, y)](https://pkg.go.dev/builtin#min)               | 返回多个同类型参数中的最小值；参数需为可比较类型（如数值、字符串）                            |
| [new()](https://pkg.go.dev/builtin#new)                   | 分配内存：创建指定类型的指针，指向零值初始化的该类型变量                                      |
| [panic(v)](https://pkg.go.dev/builtin#panic)              | 触发运行时恐慌（异常），终止当前 goroutine 执行；可被 recover 捕获                            |
| [print(args)](https://pkg.go.dev/builtin#print)           | 底层打印函数：输出参数内容，无换行，仅用于调试（不推荐生产环境使用）                          |
| [println(args)](https://pkg.go.dev/builtin#println)       | 底层打印函数：输出参数内容并换行，仅用于调试（不推荐生产环境使用）                            |
| [real(c)](https://pkg.go.dev/builtin#real)                | 返回复数 c 的实部，类型为 `float64`                                                           |
| [recover()](https://pkg.go.dev/builtin#recover)           | 捕获 panic 抛出的异常，恢复程序执行；仅在 defer 函数中调用有效                                |
