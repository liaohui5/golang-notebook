## 什么是GRPC

[gRPC](https://grpc.io/) 是一个高性能/开源和通用的 RPC 框架, 面向 HTTP/2 设计, 多编程语言支持, 由 google 开发并维护

::: info [什么是 RPC?]
`Remote Procedure Call`: 翻译为中文就是 `远程过程调用`, 简单理解就是通过对网络协议的封装, 将调用远程服务像调用本地函数一样简单方便
:::

::: info [什么是 gRPC]
这个g是google的意思, 代表这个 `gRPC` 是谷歌开发维护的高性能通用 `RPC` 开发框架
:::
